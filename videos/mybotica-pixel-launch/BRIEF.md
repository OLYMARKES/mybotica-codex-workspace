## Intent

Первый вертикальный Reel для ещё не запущенной MyBotica. Ролик должен не объяснять
функции продукта, а показать момент рождения бренда: из грубых игровых пикселей
постепенно собирается фирменный бот-дракон, затем появляется чистый логотип.
Ощущение — тёплый ретро-гейминг без дешёвой «неоновой» эстетики: живо, умно,
слегка волшебно и с хорошим чувством юмора.

## Assets

- `assets/mybotica-logo.png` — точный горизонтальный логотип; финальный бренд-локап.
- `assets/mybotica-logo-transparent.png` — тот же точный логотип с механически удалённым однотонным фоном для наложения.
- `assets/mybotica-character-sheet.png` — основной лист белого 2D бот-дракона; визуальная истина для персонажа.
- `assets/mybotica-character-sheet-alt.png` — дополнительный лист поз и эмоций; запасной референс.
- `assets/mybotica-mascot-hero-v2.png` — механический кроп главной фирменной позы без перерисовки.

## Customizations

- Эволюция графики: загрузочный пиксель → 8-bit силуэт → 16-bit персонаж → гладкий фирменный 2D дракон.
- Короткий игровой интерфейс: `BOOTING…`, `8-BIT`, `16-BIT`, `MYBOTICA // READY`.
- Финальный текст: «Собираем помощника по пикселю» и «Подписывайтесь на запуск».
- Финал должен удерживаться достаточно долго, чтобы прочитать логотип и призыв.
- В версии `loading-girl-v3` на финальном логотипе появляются по две длинные изогнутые ресницы у каждого глаза; они выходят из общей точки у внешнего верхнего края глаза и не меняют геометрию знака.
- Лёгкие игровые SFX допустимы; дикторский голос и длинная музыка не нужны.

## Notes

- Палитра бренда: `#0F2A24` (тёмно-зелёный), `#8C1D26` (бордовый), `#F6F2EE` (тёплый молочный).
- Использовать белого 2D бот-дракона как единственного персонажа. Не смешивать его с зелёным 3D-драконом.
- Не превращать ролик в продуктовую презентацию: одна идея, один визуальный трюк, один CTA.
- Первый и последний кадр должны быть совместимы по цвету/геометрии, чтобы ролик мог зациклиться.
