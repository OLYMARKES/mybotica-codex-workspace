# Цветовые версии картонного персонажа

- `refs/` — активная рабочая версия: картонный мальчик с глубокими синими шипами и крылом `#2F6794`.
- `refs-blue-v2/` — контрольная копия активной синей версии.
- `refs-burgundy-v1/` — архив предыдущей бордовой версии.

В новых генерациях использовать только `refs/` или `refs-blue-v2/`. Бордовый разрешён для отдельного реквизита, но не для анатомии персонажа.
