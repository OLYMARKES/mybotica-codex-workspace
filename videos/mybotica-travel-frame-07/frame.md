# Visual direction

Concept angle: после картонного хаоса ролик заканчивается спокойной, точной фирменной плашкой; MyBotica выглядит единственным персонажем, который всё контролирует.

- Использовать точный логотип без перерисовки.
- Тёмно-зелёный фон и кремовый текст — основа кадра.
- Золотой цвет только для рубрики и финальной шутки.
- Синий — только как очень мягкая глубина фона.
- Без чёрного, стеклянных карточек и случайных декоративных элементов.
