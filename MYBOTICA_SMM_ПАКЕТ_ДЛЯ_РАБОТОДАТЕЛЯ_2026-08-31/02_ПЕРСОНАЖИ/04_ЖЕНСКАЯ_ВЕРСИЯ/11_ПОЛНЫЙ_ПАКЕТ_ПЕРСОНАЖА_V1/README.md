# MyBotica Girl — полный пакет персонажа V1

## Эталон

`00_MASTER_MYBOTICA_GIRL_V8.png` — утверждённая основа персонажа после Impeccable-аудита.

Неизменные признаки:

- длинная прямоугольная голова и фирменная мордочка MyBotica;
- белое тело и тёмно-зелёный контур;
- бордовые шипы, крыло и спинные пластины;
- две круглые тёмно-зелёные точки-глаза;
- у каждого глаза две поднятые реснички, выходящие из одной общей точки;
- никаких платков, одежды, волос, розового цвета и макияжа.

## Назначение

Это полный концептуальный лист персонажа для выбора поз и подготовки контента. Для финальной публикации нужную позу следует вынести в отдельный файл, проверить количество шипов и ресниц, вычистить контур и подготовить прозрачный PNG.

## Генерация

Пакет создан встроенной генерацией изображений по четырём отдельным промптам: ракурсы, эмоции, рабочие действия и движения. Во всех промптах `00_MASTER_MYBOTICA_GIRL_V8.png` использовался как строгий эталон внешности, палитры и конструкции ресниц.
