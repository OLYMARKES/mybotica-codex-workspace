# Iteration Loop

Run this loop on every carousel change:

1. Edit content in `source/` and layout in `build/`.
2. Export slides from the target build variant.
3. Review slide count, readability, and visual consistency.
4. Update `status.yaml` (`updated_at`, `agent`, `notes`).
5. Keep only one canonical build in `manifest.yaml`.

## Review checklist

1. Does each slide contain one core idea?
2. Does the cover communicate outcome or hook?
3. Does the final slide include a clear CTA?
4. Are dimensions correct (`1080x1350` unless intentionally overridden)?
5. Are exported files traceable to the chosen build variant?
