# QA checklist (Instagram carousel)

## Copy
- Cover readable in < 1s without context.
- One idea per slide.
- No walls of text (2–6 lines per slide; short lines).
- Proof exists (numbers, case, before/after).
- CTA is concrete (one action).

## Design
- 2 font weights max; consistent grid/margins.
- Strong contrast; one accent color.
- All slides share the same rhythm (headers, bullets, footer).
- Safe margins respected (no text hugging edges).

## Publishing
- First comment prepared (keywords/links if needed).
- Caption supports the carousel (no repeating the same text).
- Alt text ready (optional but recommended).
