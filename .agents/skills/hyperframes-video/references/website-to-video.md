# Website to Video

Use this flow when the user gives a URL or asks to turn a website into a promo, explainer, teaser, or social ad.

## Workflow

1. Capture and summarize the site.
2. Write a compact brand/design note from the site.
3. Write the narration script.
4. Turn the script into a beat-by-beat storyboard.
5. Generate voiceover or map existing audio timings.
6. Build compositions from the storyboard.
7. Validate, preview, render, and leave handoff notes if the work will continue later.

## What to capture first

- product or brand name
- core offer and audience
- headline/subheadline language
- dominant colors and typography
- hero assets, screenshots, logos, UI patterns
- overall tone: calm, premium, technical, playful, aggressive

## Output artifacts

Create these in the project when the job is substantial:

- `DESIGN.md`: palette, typography, tone, anti-patterns
- `SCRIPT.md`: narration text and intended duration
- `STORYBOARD.md`: scene-by-scene beats, visuals, transitions, asset usage

If narration is generated, also expect:

- `narration.wav` or similar
- transcript/timestamp output used to align captions and scene timing

## Practical rules

- Let narration or a real beat plan drive scene durations; do not guess.
- Audit the site assets before building scenes so the composition does not depend on missing files.
- Keep each scene visually active; avoid static screenshots that never move.
- Validate every composition before calling the job done.
